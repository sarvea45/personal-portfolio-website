# Personal Portfolio Website

A modern, fully responsive, and animated personal portfolio built to showcase projects, skills, and professional experience.

**Author**: Kosuri Sarveswara Rao  
**Live Site**: [https://sarveswararao-kosuri-portfolio.vercel.app/](https://sarveswararao-kosuri-portfolio.vercel.app/)

## Tech Stack

- **Frontend Framework**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Scrolling**: React Scroll
- **Deployment**: Vercel

## Key Features

- **Responsive Design**: Flawlessly adapts to mobile (375px), tablet (768px), and desktop (1280px) breakpoints.
- **Advanced Animations**: Includes smooth parallax scrolling effects and staggered on-scroll reveals.
- **Accessibility**: Fully respects the `prefers-reduced-motion` CSS media query.
- **Performance Optimized**: Built for speed and high Lighthouse scores.

## Local Setup Instructions

Follow these steps to run the portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sarvea45/personal-portfolio-website.git
   cd "Personal Portfolio Website"
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the site:**
   Open your browser and navigate to the URL provided in the terminal (typically `http://localhost:5173`).

5. **Build for production:**
   ```bash
   npm run build
   ```
